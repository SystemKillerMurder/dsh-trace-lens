# dsh-trace-lens

A [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) (dsh) plugin that shows a session as a Langfuse-style trace: turns, model calls, and tool calls as a tree or timeline, with the input, output, and metadata of each observation. It can also import offline session logs for analysis.

[中文说明](README.zh.md)

## Features

- **Trace tab** in every session view. The left pane lists the trace, one SPAN per turn, a GENERATION per model call, and a TOOL per tool call, switchable between a tree and a timeline. The right pane shows the selected observation: status, latency, time to first token, provider and model, token usage, and formatted or raw JSON input, output, and metadata.
- **Status colors**: a failed model call marks its turn red; a turn whose only failures are tool calls is marked yellow; running is green; finished turns are blue.
- **Session analysis** under Settings: import a `session.v4.jsonl` log, its `.zstd` or `.gz` compressed form, or a JSON array of session events, and open it in a full-screen trace view. Imported data stays in the window's memory and is not written to local sessions.

## Install

```sh
dsh plugin --profile <profile> add dsh-trace-lens
```

Restart dsh after installing. The plugin needs the web client (`dsh web` or the desktop app).

## Development

```sh
npm install
npm run build   # regenerates client.js from the source modules
npm test
```

`client.js` is generated by `build.mjs` and is committed so the plugin installs without a build step. Edit `data-model.js`, `session-import.js`, `view.js`, `import-view.js`, or `steady-tabs.js`, then rebuild.

To try a local checkout, link it into a profile:

```sh
dsh plugin --profile <profile> add link:/path/to/dsh-trace-lens
```
